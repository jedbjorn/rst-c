# Revit ribbon command index

Every stock ribbon command the [Ribbon Tool Census](README.md) found, one row each, grouped by ribbon tab. 709 ids across Revit 2026 and 2027 (2026: 667, 2027: 688).

Generated by `tools/census/index.py` from the committed tables; nothing here is measured again. The same data as plain text: [`commands.tsv`](commands.tsv) (one row per id, both years), `<year>/matrix.tsv` (one column per context), `<year>/full.tsv` (every place and context, every column).

## How to read a row

- **Id**: the command id (`RevitCommandId.Name`). `CustomCtrl_…` ids are Autodesk add-in buttons that ship with Revit.
- **Label**: the English ribbon text. **What Revit calls it**: the one-line description Revit wrote beside the id in its own journal when the census started the tool. Blank for 235 of the 709 ids: the journal had none, or the tool was never started (containers, greyed and skipped ids).
- **Ribbon place**: the tab › panel where Revit draws it (the panel's English title).
- **Ran in** (2026, 2027): in how many contexts the id executed, out of how many it was found in (`3/9`); `-` means the id was not in that year's ribbon; `container` marks a split button, combo or gallery that holds other commands and is not one itself. An id that Revit greys out with nothing selected shows `0/9`: `<year>/matrix.tsv` says which. A context is a file kind and view (`project/FloorPlan`, `family/OST_Doors/OneLevelBased/FloorPlan`); the id's places in it are folded into one result, executes first.
- **Project views it runs in** (Revit 2027): the project view types where it executes with nothing selected.

Revit 2026 is build 2026.4.10 (26.4.10.51); 2027 is build 2027.3 (27.3.0.28). English Revit, nothing selected, no contextual tabs. Third-party add-ins are not in this index. For the rules, columns and limits see the [census README](README.md).
