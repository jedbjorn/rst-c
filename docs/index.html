New Feature highlight · v3.4

Search-It. Find any tool. Run it.

You know the tool exists, just not which tab it lives on. Click Search-It on the RST panel, type a few letters, and click the result. Revit starts the tool as if you had found it on the ribbon.

  • Typos are fine: “algn” finds Align
  • Press Enter to keep a word as a chip and narrow the list
  • Every result shows its Tab › Panel, so you learn where it lives
  • Pan and zoom the view behind it without closing the window

From curated to ready

One profile. Three simple steps.

Build the ribbon once, share the whole package, and let each person load it in a click. Commands, icons, colours, and branding travel together.

  1. 1

    Build

    Choose commands from any tab, organise panels and stacks, and add the colours, icons, branding, and resources your team needs.

  2. 2

    Share

    Export one self-contained .zip with the profile, icons, colours, and branding included.

  3. 3

    Load

    Import, preview, and apply. Everyone gets the same polished ribbon, with live switching and no Revit restart.

Outside Revit, still RST

Set up before you start.

The small RST tray app brings profile switching, updates, companion apps, and health information together in one place. Nothing in Revit depends on it.

  • Apply a profile or restore all add-ins before launch
